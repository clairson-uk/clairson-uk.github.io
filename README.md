# Clairson – Be seen clearly by AI

Website for Clairson: AI visibility for letting and estate agents across the UK, based in Milton Keynes.
Single file (`index.html`), no frameworks. `CLAUDE.md` is the business brain for Claude Code.

## Go live (free)
1. GitHub account with username `Clairson-uk`.
2. Public repo named exactly `clairson-uk.github.io` containing `index.html`, `CLAUDE.md` and this README.
3. Settings → Pages: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Live at https://clairson-uk.github.io within a few minutes.

## Use with Claude Code
Open claude.ai/code, pick this repo, and start with:
"Read CLAUDE.md first; it's the brain of my business. Keep replies short; I'm on my phone."
